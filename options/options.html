Resumes

Upload the actual file for each resume — JobFill stores it locally and can attach it to a site's "Resume/CV upload" field automatically. Star the one to use by default. This works for real file inputs, which is how virtually every ATS (Greenhouse, Lever, Workday, SmartRecruiters, etc.) implements resume upload even when it's styled as a drag-and-drop box; a handful of fully custom upload widgets that never render a real file input can't be reached this way, and you'll still attach those yourself.

Privacy

Your profile and mappings are stored only on this device (chrome.storage.local). Nothing is uploaded. JobFill's content script runs on the pages you visit only so it can detect and fill form fields there — it does not read your browsing history or run on pages where you haven't opened a form.
